¿Qué es Git?

Git es un sistema de control de versiones que permite gestionar cambios en archivos y proyectos de software. Es ampliamente utilizado para el desarrollo colaborativo.

Características

  • Distribuido (no depende de un servidor central)
  • Rápido y eficiente
  • Permite trabajo en equipo
  • Control de versiones completo

Comandos básicos

  • git init: Inicializa un repositorio
  • git add: Agrega archivos
  • git commit: Guarda cambios
  • git push: Sube cambios al repositorio remoto
